Revise

Edit any PDF like a document.

A native Mac app. Click into the text and type: paragraphs reflow, lists and tables hold together, and it saves straight back to PDF. No conversions.

Download for Mac

v0.2.1 · Apple silicon · macOS 12+ · Source

or install with Homebrew

$ brew install --cask tcmarkfeld/tap/revise

What it does

  • Type anywhere Click into any text and edit it. Enter splits paragraphs, Backspace joins them.
  • Keeps the structure Headings, lists, columns, and tables come through as real, editable structure.
  • Saves as a PDF ⌘S writes back to the same file, so it still opens in Preview, Acrobat, or a browser.
  • Your files are safe It keeps your original, autosaves as you go, and asks before discarding changes.

Install

  1. Download Revise.dmg and open it.
  2. Drag Revise into your Applications folder.
  3. Open a PDF with it: right-click the file, then Open With → Revise, or press ⌘O in the app.

Using Homebrew instead? The command above installs Revise into Applications for you, and brew upgrade keeps it current.

Works best with

Text-based documents like resumes, letters, reports, and forms. Revise reads the PDF’s own text, so scanned pages can’t be edited, and very design-heavy files may not rebuild perfectly. Found one that doesn’t come out right? Open an issue.
